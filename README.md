# bet1x — Pitch Demo (No Database, No Backend)

A pure **HTML + CSS + JS** version for showing/pitching the product. There is
no PHP, no MySQL, no server of any kind — every "live" number (active
players, bet totals, results, activity feed) is generated by JavaScript with
fake/dummy data. Wallet balance and your bet history are kept in the
browser's `localStorage` only, purely so the demo feels consistent while you
click between pages during a pitch — nothing is sent anywhere.

## How to open it

Just double-click `index.html` to open it in a browser — no server, no
install, no setup. (Or, for slightly smoother font/asset loading, run a
simple local server: `python3 -m http.server` from this folder, then visit
`http://localhost:8000`.)

## What's inside

```
bet1x-demo/
├── index.html      Landing dashboard: hero, KPI stats, result "pulse" strip, room grid
├── win.html         Sapre room  (30s rounds)
├── win1.html         Becone room (1 min rounds)
├── win2.html         Emred room  (3 min rounds)
├── win3.html         VIP room    (5 min rounds)
├── parity.html       Admin monitor: bet distribution by color / number / size
└── assets/
    ├── css/style.css     all design tokens + component styles
    └── js/
        ├── dummy-data.js  fake data generators (results, KPIs, activity, bet distribution)
        └── ui-common.js   countdown ring, pulse strip renderer, activity feed loop, demo wallet
```

## What's simulated vs. real

| Feature | Status |
|---|---|
| Countdown timers per room | Real (client-side JS timer) |
| Placing a bet / selecting color-number-size | Real interaction, fake settlement |
| Win/loss + payout on round end | Simulated with a random draw, client-side only |
| Wallet balance | Fake, stored in your browser only (`localStorage`) |
| "612 players online", KPIs, activity feed | Randomly generated for visual effect |
| Admin bet distribution charts | Randomly generated, refreshes every few seconds |

## Reset demo data

There's a "Reset demo data" link in the dashboard footer that clears the
local wallet/history and reloads with a fresh 1,000 coin balance.
